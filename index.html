GBA

กด Play ใช้ลูกศรเพื่อเดินหรือเลือกเมนู มีปุ่ม A, B, L, R, Start และ Select การจับคู่ปุ่มคีย์บอร์ดของ EmulatorJS ดูและเปลี่ยนได้จากเมนูเครื่องเล่น → Controls / ตั้งค่าปุ่ม → Player 1 ให้ตรวจช่องของแต่ละปุ่มแล้วกดคีย์ที่ต้องการ

A มักใช้ตกลงหรือคุย B ใช้ย้อนกลับ Start เปิดเมนูหรือเริ่มเกม L/R มีหน้าที่ตามเกม ปุ่มที่ใช้จริงขึ้นกับเกมนั้น

NDS

ใช้คีย์บอร์ดผ่านเมนู Controls เช่นเดียวกับ GBA แต่มี X และ Y เพิ่มมา จอบนใช้ดูภาพ ส่วนจอล่างใช้เมาส์คลิก กดค้าง หรือลากตามเกม จอสัมผัสไม่ได้ตอบสนองทุกฉาก บางเกมต้องกด Start หรือ A เพื่อผ่านหน้าเริ่ม

ตั้งปุ่ม A/B/X/Y/L/R/Start/Select แยกกันใน Player 1 อย่าใช้คีย์เดียวกันหลายปุ่มถ้าไม่ต้องการให้เกมรับพร้อมกัน

D-pad ใช้เลื่อนเมนู แอนะล็อกมักใช้เดินตัวละคร การตกลงหรือย้อนกลับอาจใช้ × หรือ ○ ตามเกม PSP ไม่มี L2/R2 หรือแอนะล็อกขวา

Sword Art Online Infinity Moment บนคอม: เมื่อหน้าจอเกมระบุ “○ Enter” ให้กด Z เพื่อยืนยัน ไม่ใช่ Enter บนคีย์บอร์ด หากระบุ “× Back” ให้กด X ใช้ลูกศรเลือก Yes / No ส่วน Enter บนคีย์บอร์ดคือปุ่ม Start ของ PSP

ถ้ากดปุ่มแล้วเกมไม่ตอบสนอง ให้คลิกบริเวณภาพเกมหนึ่งครั้งเพื่อให้ตัวเล่นรับคีย์ และตรวจผังปุ่มใน Controls → Player 1 หากตั้งคีย์เองไว้ ให้ใช้คีย์ที่จับคู่กับ ○ หรือ × ของคุณ ปุ่ม BACK บนแถบเว็บใช้ปิดตัวเล่นและกลับไปหน้าคลังเกม

แนะนำเปิดเว็บโดยตรงใน Chrome หรือ Safari กด Play แล้วรอโหลดจนจบ ใช้สองนิ้วกดปุ่มพร้อมกันได้ เปิดเสียงหลังแตะเว็บครั้งแรกหากเบราว์เซอร์ยังล็อกเสียง

กดค้างที่ปุ่มย่อจอขณะเต็มจอเพื่อซ่อนแถบเมนู แตะลูกศรมุมซ้ายบนเพื่อเรียกกลับ หากต้องการย้ายปุ่ม เลือกไอคอนปรับปุ่ม → ลากปุ่ม → เสร็จ ปุ่ม “คืนค่าเดิม” คืนค่าของแนวจอที่ใช้อยู่

GBA

กด D-pad เพื่อเดิน ใช้ A/B ทางขวาและ L/R ด้านบน Start/Select อยู่ด้านล่าง กดไอคอนปรับปุ่มเพื่อย้าย ขยาย ลดความชัด หรือเปลี่ยนสกิน เมื่อเสร็จให้กด “เสร็จ” เว็บจำค่าของแนวจอที่กำลังใช้ในเครื่องนี้

NDS

มี D-pad กับ A/B/X/Y พร้อม L/R ใช้นิ้วแตะหรือลากบนภาพจอล่างได้ทั้งแนวตั้งและแนวนอน หากแตะไม่ติดให้ตรวจว่าไม่ได้แตะปุ่มควบคุมที่ทับอยู่ และเกมอยู่ในฉากที่รับจอสัมผัส

กดปุ่มหมุนเพื่อสลับแนว ถ้าเครื่องไม่ยอมหมุน ให้เปิดหมุนหน้าจออัตโนมัติแล้วเอียงมือถือเอง อย่าล็อกแนวจอไว้ในระบบ

3DS

ใช้แป้นทิศทางแทน Circle Pad ปุ่ม A/B/X/Y และ L/R อยู่รอบจอ จอล่างรับการแตะและลากเช่นเดียวกับ NDS เล่นแนวนอนช่วยเพิ่มพื้นที่ กรณีเกมช้าลองปิดแอปอื่นและเล่นที่ความเร็วปกติ

PSP

ถือแนวนอนเพื่อให้จอและปุ่มมีพื้นที่ วงแดงคือ D-pad สำหรับทิศทางและเมนู วงเทาคือแอนะล็อกสำหรับเคลื่อนที่ แยกจากกัน ปุ่ม Fast/Slow ใช้เร่งหรือชะลอเกม แผงปุ่มใช้สัญลักษณ์ตาม PSP จริง: △ อยู่บน □ อยู่ซ้าย ○ อยู่ขวา × อยู่ล่าง ด้านซ้ายมี D-pad และแอนะล็อกแยกกัน ปุ่ม L/R คือปุ่มไหล่ ส่วน Start/Select ใช้เปิดเมนูหรือฟังก์ชันตามเกม

เลื่อนเมนูด้วย D-pad เดินด้วยแอนะล็อกในเกมที่รองรับ แล้วกด × หรือ ○ ตามคำแนะนำของเกม ปุ่ม △ และ □ มีหน้าที่ต่างกันในแต่ละเกม ใช้หลายนิ้วกดพร้อมกันได้ PSP ไม่มีจอสัมผัส จึงเลือกเมนูด้วยการจิ้มภาพเกมไม่ได้ และไม่มี L2/R2 หรือแอนะล็อกขวา

เล่นด้วยจอยคอนโทรลเลอร์
GBA และ NDS
  1. ต่อจอย USB หรือจับคู่ Bluetooth กับคอม/มือถือก่อนเข้าเว็บ ตรวจให้ระบบเห็นจอยแล้ว
  2. เปิดเกม กดปุ่มบนจอยหนึ่งครั้งเพื่อให้เบราว์เซอร์ตรวจพบ
  3. เปิดเมนูเครื่องเล่น → Controls → Player 1 เลือกจอยและจับคู่ปุ่มตามที่ถนัด ชื่อเมนูอาจต่างตามรุ่นแกนจำลอง
  4. ทดสอบทิศทาง A/B และ Start ก่อน สำหรับ NDS ต้องตั้ง X/Y เพิ่ม จอสัมผัสยังใช้เมาส์หรือนิ้ว

ชื่อปุ่มจอย Xbox และ Nintendo อาจสลับกัน ให้จับคู่ตามปุ่มเครื่องเกมที่ปรากฏในเมนู หากไม่เจอจอย ลองถอดต่อใหม่ กดปุ่มหนึ่งครั้ง และใช้เบราว์เซอร์ที่รองรับ Gamepad

3DS

3DS รับจอยมาตรฐานอัตโนมัติ: ปุ่มล่าง B ขวา A ซ้าย Y บน X พร้อม L/R และ Start/Select ใช้ก้านซ้ายเดินและก้านขวาเป็น D-pad กดไอคอนจอยเพื่อทดสอบปุ่ม จอสัมผัสยังใช้นิ้วหรือเมาส์ จอยที่เบราว์เซอร์ไม่ระบุเป็น standard ต้องใช้การแปลงเป็นคีย์บอร์ด

PSP

เชื่อมต่อจอยแล้วกดปุ่มหนึ่งครั้ง เปิดเมนู EmulatorJS → Controls → Player 1 เพื่อตรวจการจับคู่ D-pad แอนะล็อก ปุ่ม △ / ○ / × / □ และ L / R / Start / Select ให้ตรงกับจอยที่ใช้

การบันทึกเกมและรหัสซิงก์
วิธีใช้ร่วมกัน

1. เซฟในเกม — ใช้เล่นต่อข้ามเครื่อง

เปิดเมนู Save ของตัวเกมและบันทึกให้เสร็จ ตั้งรหัสซิงก์ส่วนตัวเพื่อให้เว็บส่งเซฟไปเก็บเมื่อออนไลน์เป็นระยะ ก่อนออกให้เซฟในเกมแล้วกด BACK รอจนเว็บกลับคลังเกม อย่าปิดแท็บหรือปิดเน็ตขณะกำลังส่งเซฟ

บนเครื่องใหม่ใช้รหัสเดิมและเปิดเกมเดียวกัน รหัสที่มีหน้าต่างอื่นใช้อยู่จะเข้าไม่ได้ ให้ปิดหน้าต่างเดิมก่อน ถ้าปิดผิดปกติหรือเน็ตหลุด รอไม่เกินประมาณ 10 วินาทีแล้วลองใหม่ รหัสนี้เป็นกุญแจเข้าเซฟและเกมโปรด ไม่ใช่บัญชีที่มีระบบกู้รหัส อย่าแชร์กับคนอื่น

2. Save บนแถบ — เซฟด่วน

เก็บสถานะขณะนั้น เช่น ก่อนสู้บอสหรือกลางฉาก Save ครั้งใหม่ทับจุดเดิม Load จะย้อนเกมไปจุดที่เซฟไว้และขอยืนยันก่อน ความคืบหน้าหลังจุดนั้นจะหาย เซฟด่วนแยกจากเซฟในเกม เมื่อใส่รหัสซิงก์และขึ้นว่าซิงก์สำเร็จ จะใช้ Load บนเครื่องอื่นด้วยรหัสเดิมและเกมเดียวกันได้ ควรใช้แกนเครื่องเล่นรุ่นเดียวกัน เซฟที่ใหญ่เกินขีดจำกัดหรือส่งออนไลน์ไม่สำเร็จจะยังเก็บในเครื่อง

การเปลี่ยนรหัสทำให้เว็บใช้เซฟและเกมโปรดของรหัสใหม่ ข้อมูลของรหัสเก่ายังอยู่ แต่ต้องกลับไปใช้รหัสนั้นเพื่อเรียกดู หลีกเลี่ยงล้างข้อมูลเว็บไซต์โดยไม่สำรองเซฟ

GBA และ NDS

เปิดเมนูเครื่องเล่น → Export Save File เพื่อดาวน์โหลดเซฟในเกม Import Save File ใช้นำกลับสำหรับเกมเดียวกัน

3DS มีระบบเซฟเฉพาะของแกน ควรตรวจว่าเซฟในเกมและการซิงก์สำเร็จก่อนรีโหลด

PSP

เซฟผ่านเมนูในเกมก่อนออก และทดสอบเซฟด่วน / โหลดด่วนของเกมนั้นก่อนพึ่งพาเพียงอย่างเดียว ตรวจข้อความซิงก์สำเร็จก่อนเปลี่ยนเครื่อง การซิงก์เซฟไม่ได้ย้ายไฟล์เกมหรือแคชไปด้วย เครื่องใหม่ยังต้องโหลดและเตรียมเกม

ปุ่มต่าง ๆ บนแถบเมนู
วิธีใช้ร่วมกัน
Save/Load
บันทึกและโหลดเซฟด่วน ไม่ใช่ปุ่มเซฟในเมนูเกม
FastFast/SlowSlow
กดครั้งเดียวเพื่อเปิดค้าง กดปุ่มเดิมอีกครั้งกลับความเร็วปกติ เปิดโหมดหนึ่งจะปิดอีกโหมด หากเกมช้าอยู่แล้ว Fast อาจไม่ช่วยเมื่อเครื่องประมวลผลเต็มกำลัง
เสียง
เปิด/ปิดหรือปรับระดับเสียงเกม ถ้าไม่มีเสียงให้แตะเว็บก่อนแล้วตรวจระดับเสียงของเครื่องด้วย
หมุนจอ
สลับแนวตั้ง/แนวนอน การอนุญาตหมุนขึ้นกับเบราว์เซอร์และการตั้งค่าของมือถือ
เต็มจอ / ย่อจอ
กดปกติเพื่อเข้า/ออกเต็มจอ กดค้างขณะเต็มจอเพื่อซ่อนแถบ แตะลูกศรมุมซ้ายบนเพื่อแสดงแถบ
ปรับปุ่ม
ลากตำแหน่ง เปลี่ยนขนาด ความชัด ซ่อนปุ่มบางกลุ่ม และเลือกสกิน ค่าตำแหน่งเก็บแยกตามเครื่องและแนวจอ
BACKBACK
ออกเกมกลับคลัง โดยขอยืนยันก่อน ควรเซฟในเกมก่อนออกทุกครั้ง
รหัสซิงก์
กำหนดรหัสเพื่อเรียกเซฟในเกมและรายการโปรดจากเครื่องอื่น ต้องไม่มีคนใช้รหัสนั้นพร้อมกัน
PSP

แถบบาร์เรียง เซฟด่วน → โหลดด่วน → ลำโพงปรับเสียง → ย่อ/ขยายจอ → ซิงก์เซฟ ตามเครื่องอื่น แตะลำโพงเพื่อปรับ 0–100% หรือแตะสองครั้งเพื่อปิดเสียง ปุ่ม Back ใช้ออกจากเกม ส่วน Controls ใน EmulatorJS ใช้ตรวจหรือเปลี่ยนคีย์บอร์ดและจอย แผงสัมผัส PSP แสดงเฉพาะปุ่มของเครื่องจริง

อัปโหลด แก้ข้อมูล และแก้ปัญหาเบื้องต้น
วิธีใช้ร่วมกัน

ปุ่มเพิ่ม/แก้เกมมีให้ผู้ดูแลที่ล็อกอิน เลือก ROM ตั้งชื่อ เครื่องเกม รูปปก และคำอธิบาย แล้วกดบันทึก ระหว่างส่งไฟล์ย่อหน้าต่างเพื่อทำงานอื่นได้ รักษาเน็ตและอย่าปิดแท็บต้นทาง เมื่อเสร็จจะมีแจ้งเตือนและหน้าต่างย่อจะปิด

ในหน้าแก้ไขเกม กด “ดาวน์โหลด ROM” ใต้ช่องเลือกไฟล์เพื่อเก็บ ROM ปัจจุบันไปแก้ไขต่อ ชื่อไฟล์และนามสกุลจะคงเดิม มีสถานะการโหลดและปุ่มยกเลิก เมื่อแก้ไฟล์เสร็จ เลือก ROM ใหม่แล้วบันทึกเพื่อแทนที่ไฟล์เดิม

แก้แค่ชื่อหรือคำอธิบายไม่จำเป็นต้องเลือก ROM ใหม่ ชื่อที่มี TH หรือ Thai ช่วยเลือก “มีแปลไทย” ให้อัตโนมัติ แต่ผู้ดูแลแก้เองได้

  • เกมไม่เริ่ม: ตรวจรูปแบบ ROM และความเข้ากันได้กับแกนเครื่องเล่น
  • เกมช้า: ปิด Slow ลดแอปเบื้องหลัง และลองเบราว์เซอร์โดยตรง การดาวน์โหลดเร็วไม่ได้หมายถึงการจำลองเกมจะเร็วเท่ากัน
  • ปุ่มหรือจอเพี้ยน: ลองเปลี่ยนแนวจอแล้วคืนค่าตำแหน่งปุ่ม หากยังผิดให้รีโหลดหลังเซฟ
  • เซฟไม่ตามมา: ตรวจว่าใช้รหัสและเกมเดียวกัน รอซิงก์ขณะมีเน็ตก่อนย้ายเครื่อง
  • พื้นที่อัปโหลดไม่พอ: ผู้ดูแลดูพื้นที่แต่ละบริการในแดชบอร์ด หรือย้ายเกมไปบริการที่ยังมีพื้นที่ อย่าเพิ่มเพดานเกินโควตาที่ตั้งไว้
3DS

ไฟล์เกมต้องเป็นรูปแบบที่แกนรองรับและถอดรหัสแล้ว หากโหลดครบแต่ไม่เริ่ม ให้ตรวจความเข้ากันได้ของเกม

PSP
  • เลือกเครื่อง PSP และไฟล์ .iso / .cso / .pbp หากอยู่ใน ZIP หรือ RAR ให้แตกไฟล์ก่อน
  • แจ้งว่าต้องรองรับ COOP/COEP: เปิดผ่านเซิร์ฟเวอร์ทดสอบหรือเว็บที่ตั้งค่าแล้ว อย่าเปิดไฟล์ HTML โดยตรง
  • โหลดครบแต่จอดำ: ตรวจไฟล์เกมและความเข้ากันได้กับแกน PPSSPP การอัปโหลดสำเร็จไม่ได้รับรองว่าเล่นได้
  • เล่นกระตุก: ใช้ความละเอียดปกติ ปิดแอปเบื้องหลัง และปิดการเร่งความเร็ว ความเร็วโหลดกับความลื่นระหว่างเล่นเป็นคนละส่วน
